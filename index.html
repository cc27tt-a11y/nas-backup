NAS-Backup

NAS-Backup is a personal backup application operated by its owner. It uses rclone on a privately operated NAS to back up selected files to the owner's Google Drive and restore them when needed.

Google Drive access

Google authorization allows the application to access Google Drive within the permissions granted by the owner, for backup and restoration purposes.

Personal use

This application is for the owner's personal use and does not offer a public backup service. This website provides application information only; it does not host backup files or collect Google credentials.
