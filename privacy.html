NAS-Backup Privacy Policy

Last updated: September 24, 2026

About this application

NAS-Backup is a personal backup application using rclone on the owner's privately operated NAS. It is intended solely for the owner's use, not as a public backup service.

Data accessed and purpose

Within the Google Drive permissions granted by the owner, the application accesses file contents and metadata, including file names, folder information, sizes and modification times, to perform owner-directed backup, file management and restoration.

Storage and protection

Backup files are stored in the owner's Google Drive. Restored files and local source files remain on owner-controlled devices. OAuth credentials and tokens are stored in the owner's local application configuration. Google API connections use HTTPS.

Operational logs may contain file names and transfer details and remain on owner-controlled devices unless the owner chooses to share them.

Data sharing and use

Files and necessary metadata are transmitted to Google to provide the requested storage and backup functions. The application does not sell Google user data, use it for advertising, or use it to train AI models. It does not intentionally share backup contents with unrelated third parties.

Retention and deletion

Files are retained until the owner deletes them or a configured retention rule removes them. The owner can delete cloud files through Google Drive and separately remove local files, logs and application credentials. Files in Google Drive Trash may need to be permanently deleted to complete removal.

Revoking access

The owner can revoke the application's access through Google Account third-party connection settings. Revoking access does not automatically delete existing backups or local copies.

This website

This static website provides application information. It does not collect Google credentials, accept file uploads or host backup data. It includes no application-added analytics or advertising trackers. GitHub Pages hosts this website and may process visitor technical information under GitHub's own privacy statement.

Contact

For questions about this application or policy, contact the maintainer through the project issue tracker . Do not post passwords, tokens or private files there.
